FACE RECOGNITION BASED ATTENDANCE MONITORING SYSTEM

A high-speed, contactless classroom attendance automation platform developed using Python, OpenCV LBPH, and FastAPI.

🌟 Key System Highlights

⚡ Zero-Lag Processing

Frame skipping, in-memory face cache, and single-instance CLAHE prevent camera stutter or UI freezing.

🎙️ Voice Announcements

Speaks student names upon successful attendance and immediately warns when an unknown or unregistered face is detected.

📊 Multi-Format Sync

Real-time logging to SQLite, auto-export to formatted Excel & CSV with Faculty and Period breakdowns.

🧪 Interactive Trial & Samples

Test the live speech synthesizers and view how the system processes attendance and handles unknown detections below:

🔊 Sample 1: Recognized Student (Present)

Simulates voice notification when registered student is verified.

🔊 Sample 2: Wrong / Unknown Face Detected

Simulates security alert when face does not match class roster.

🎓 Workflow Step-by-Step

  1. Sign In / Register: Authorized faculty logs into the system.
  2. Face Capture: Capture 15 photos per student (via Webcam, File Upload, or Mobile QR link).
  3. Face Training: Train LBPH model on captured photos.
  4. Face Testing: Verify recognition without marking attendance.
  5. Start Attendance: Choose subject, faculty, period and let camera auto-mark present with voice confirmations.
